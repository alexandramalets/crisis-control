# Демонстрационные данные

`demo_indicators.csv` — синтетический набор показателей организации за 36 месяцев (2023-01 … 2025-12). Создаётся скриптом `generate_demo.py` (результат детерминирован).

Формат («широкий», предложен в ARCHITECTURE.md, требует согласования — вопрос 7 в IMPLEMENTATION_PLAN.md): строка — период `ГГГГ-ММ`, столбцы — коды показателей.

| Код | Показатель | Единица |
|---|---|---|
| `revenue` | Выручка | руб. |
| `sales_volume` | Объём продаж | шт. |
| `profit` | Прибыль | руб. |
| `receivables` | Дебиторская задолженность | руб. |
| `payables` | Кредиторская задолженность | руб. |
| `inventory` | Запасы | руб. |
| `cash` | Денежные средства | руб. |
| `cf_operating` | Денежный поток от операционной деятельности | руб. |
| `cf_investing` | Денежный поток от инвестиционной деятельности | руб. |
| `cf_financing` | Денежный поток от финансовой деятельности | руб. |

Заложенные особенности (для проверки аналитических процедур):

- с 2025-07 — снижение выручки и рентабельности, рост дебиторской задолженности и запасов, сокращение денежных средств;
- выбросы: запасы в 2024-03, дебиторская задолженность в 2024-11;
- годовая сезонность выручки.
