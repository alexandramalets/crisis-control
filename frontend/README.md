# Клиентское приложение (frontend)

React 19, JavaScript (только `.js` и `.jsx`), Vite 7, CSS, Recharts, Axios. Бизнес-логики в клиенте нет: отображение и обращения к серверу по `/api/v1`.

Сейчас: каркас интерфейса по визуальному референсу (шапка, боковое меню, страницы разделов, общие компоненты). Аналитические значения не выдумываются; загрузка, запуск анализа и отчёты будут подключены к API на следующем этапе.

## Режим разработки

Нужен Node.js 20.19+ или 22.12+.

```powershell
cd frontend
npm ci
Copy-Item .env.example .env     # при необходимости изменить DEV_BACKEND_URL
npm run dev                     # http://localhost:5173, запросы /api проксируются на сервер
```

## Сборка для развёртывания

```powershell
npm run build                   # результат в dist/
```

В Docker сборка раздаётся nginx (`nginx/default.conf.template`). Он же проксирует `/api/` на сервер, поэтому браузер работает с одним источником (origin). Адрес сервера задаётся переменной `BACKEND_UPSTREAM`. Проверка состояния — `GET /healthz`.
